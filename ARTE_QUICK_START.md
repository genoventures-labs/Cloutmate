# ARTE Quick Start Guide

## What is ARTE?

**ARTE** (Aurora Reactive Theme Engine) is Aurora's emotional nervous system - a real-time interface adaptation system that responds to your cognitive-emotional state. It makes your workspace feel alive and responsive to how you think and work.

---

## Getting Started

### 1. ARTE is Already Running

ARTE starts automatically when you launch FocusOS. It's enabled by default in **Auto** mode, continuously adapting to your work patterns.

### 2. Where to Find ARTE

**Settings Panel:**
- Go to **Settings** → Look for **ARTE** section
- Full control over operation mode, intensity, and preferences

**Insights Dashboard:**
- Go to **Insights** → **Overview** tab
- See your current emotional state in real-time
- View recent state transitions and patterns

---

## Quick Controls

### Operation Modes

**Auto Mode** (Recommended)
- ARTE automatically detects your cognitive state
- Adapts in real-time based on your activity
- No manual intervention needed

**Manual Mode**
- You choose the emotional state manually
- Lock the interface to a specific mood
- Good for presentations or specific workflows

**Blend Mode**
- Auto detection with manual override capability
- Best of both worlds - intelligent but controllable

### Intensity Slider

Control how strongly ARTE affects the interface:
- **0-30%**: Barely noticeable (subtle hints)
- **40-70%**: Balanced adaptation (recommended)
- **80-100%**: Strong emotional resonance

## The Five Emotional States

### 🎯 Focused
**When it activates:**
- Active focus session running
- Deep work on high-priority tasks
- Minimal distractions, high concentration

**Visual signature:**
- Deep blues
- Cool shadows
- Slower, more deliberate animations
- Higher contrast

**Best for:** Deep work, complex problem-solving, creative sessions

---

### 🧠 Reflective  
**When it activates:**
- Memory Graph exploration
- Low task activity with high thought density
- Analytical, contemplative work

**Visual signature:**
- Muted purples
- Soft contrasts
- Measured timing
- Gentle atmosphere

**Best for:** Planning, reviewing, strategic thinking

---

### 🌿 Calm
**When it activates:**
- Balanced baseline state
- Steady task completion
- Neutral emotional valence

**Visual signature:**
- Kosmic blue baseline
- Neutral shadows
- Normal animation speeds
- Balanced contrast

**Best for:** General productivity, maintenance tasks

---

### ⚡ Energized
**When it activates:**
- High task completion rate
- Positive emotional valence
- Rapid execution flow

**Visual signature:**
- Bright cyan-blues
- Warm shadows
- Faster, snappier animations
- Higher contrast

**Best for:** Task sprints, momentum work, rapid execution

---

### 🌙 Fatigued
**When it activates:**
- Low completion rates
- Extended sessions without breaks
- Late hours (22:00-06:00)

**Visual signature:**
- Warmer purple tones
- Warm shadows (easy on eyes)
- Much slower, gentler motion
- Reduced contrast

**Best for:** Light tasks, winding down, rest encouragement

## Advanced Features

### Adaptive Timing
- **Enabled**: ARTE checks more frequently during high activity
- **Disabled**: Fixed 30-second check intervals

### Learning System
- **Enabled**: ARTE learns from your manual overrides
- **Disabled**: Uses only initial heuristics
- **Reset**: Clear learning data to start fresh

### Performance Stats
View in Settings → ARTE:
- Average update latency
- Total state transitions
- CPU usage estimate
- System health status

## Tips & Best Practices

### Getting the Most from ARTE

1. **Let it Learn**: Use Auto mode for 1-2 weeks to build accurate calibration
2. **Adjust Intensity**: Start at 70%, adjust based on preference
3. **Manual Overrides**: Use them when you disagree - ARTE learns from this
4. **Check Insights**: Monitor the Emotional State Indicator to understand patterns
5. **Lock When Needed**: Use Manual mode during screen sharing or presentations

### When to Use Manual Mode

- **Presentations**: Lock to Focused for professional appearance
- **Demos**: Choose a consistent state for recordings
- **Specific Moods**: Force Calm during stressful external situations
- **Testing**: See how each state looks in your workspace

### Performance Optimization

ARTE is designed for efficiency:
- Adaptive polling reduces checks when idle
- Transitions are debounced (minimum 2 minutes apart)
- Analytics caching minimizes overhead
- Target < 2% CPU usage

## Troubleshooting

### ARTE Doesn't Seem to Be Working

1. Check Settings → ARTE → Verify it's enabled
2. Look at Insights → Overview → See current state
3. Check intensity isn't set too low (< 30%)
4. Verify mode is Auto or Blend

### State Changes Too Frequent/Infrequent

**Too Frequent:**
- Shouldn't happen (2-minute minimum debounce)
- Check for rapid activity pattern changes

**Too Infrequent:**
- Normal in low-activity periods
- Manual override always works instantly

### Visual Changes Too Subtle/Intense

- Adjust intensity slider in Settings
- 40-70% is recommended range
- Remember: ARTE is designed for subtlety

### Want to Disable ARTE Temporarily

- Settings → ARTE → Toggle master switch
- Interface returns to static baseline
- Re-enable anytime without data loss

## FAQ

**Q: Does ARTE affect performance?**
A: Minimal impact - designed for < 2% CPU usage with adaptive polling

**Q: Can I create custom emotional states?**
A: Not yet - Phase 7 includes 5 core states. Custom states are a potential future enhancement.

**Q: Does ARTE work offline?**
A: Yes - all detection is local. No internet required.

**Q: Will ARTE learn my personal patterns?**
A: Yes, if Learning is enabled. It adapts thresholds based on your manual overrides.

**Q: Can I export/import ARTE settings?**
A: Not yet - but calibration data is stored in your user profile.

**Q: Does ARTE sync across devices?**
A: Not in Phase 7 - each installation learns independently.
