## 🎤 Voice Input

**What it does:** Speak your message instead of typing

**How to use:**
1. Click microphone button
2. Speak your message
3. Click again to stop
4. Review and send

**States:**
- ⚪ Gray = Ready to record
- 🔴 Red = Currently recording
- 🔇 Dimmed = Disabled (AI processing)

**Tips:**
- First use requires mic permission
- Works offline (on-device)
- Best in quiet spaces
- Can cancel anytime

---

## 💾 Save to Draft

**What it does:** Export conversation to Drafts in one click

**How to use:**
1. Have a conversation
2. Click save button
3. See "Saved!" notification
4. Find in Drafts tab

**Saves:**
- ✅ All AI responses
- ✅ Conversation title
- ✅ Tags
- ✅ Timestamp

**Note:** Button disabled if no messages yet

---

## ➕ New Conversation

**What it does:** Start a fresh chat with AI

**How to use:**
1. Click plus button
2. Confirm if unsaved changes
3. Start new conversation

**Same as before:** Just better icon!

## ❓ FAQ

**Q: Where's the info button?**  
A: Info still available in help and alerts

**Q: Can I type while recording?**  
A: No, input locked during recording for safety

**Q: What happens to my draft?**  
A: Goes to Drafts tab, editable anytime

**Q: Which platforms supported?**  
A: Facebook and Threads currently

**Q: Is voice private?**  
A: Yes! On-device processing, nothing sent to servers

**Q: Can I undo a save?**  
A: Delete from Drafts tab if needed

## ✅ Quick Start

**First Time Using Voice:**
1. Click 🎤 button
2. Allow microphone access when prompted
3. See recording indicator appear
4. Start speaking your message
5. Click 🎤 again or let it auto-stop
6. Text appears in input field
7. Edit if needed, then send

**Saving Your First Draft:**
1. Have any conversation with AI
2. Click 💾 button (top toolbar)
3. See confirmation toast
4. Open Drafts tab to find it
5. Edit or publish from there

**Switching Platforms:**
1. Look at Quick Action Tools area
2. See platform buttons with checkmarks
3. Click the platform you want
4. See blue highlight move
5. Use tools with new platform context

## 🔧 Troubleshooting

### Voice button greyed out?
→ AI is processing a message, wait a moment

### "Microphone permission required"?
→ Go to System Settings > Privacy > Microphone

### Save button greyed out?
→ Need at least one message in conversation

### Platform not highlighted?
→ Click the platform button to select it

### Recording not stopping?
→ Click mic button again or click Cancel
