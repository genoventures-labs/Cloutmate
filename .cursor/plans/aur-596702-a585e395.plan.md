# Add Emoji Picker Button and Drawer

## Overview

Add an emoji picker icon button on the left side of the chat input bar (alongside AttachmentMenuView and ActionMenuView) that opens a drawer displaying Apple emojis organized by categories. The drawer uses assistant chat style UI consistent with MentionDrawerView. Selecting an emoji inserts it at the current cursor position and closes the drawer.

## Implementation

### 1. Create EmojiButton Component

**File:** `FocusOS/Views/AIAssistant/Components/EmojiButton.swift`

Create a new button component similar to `VoiceButton.swift`:

- Circular button with gradient background (use emoji-friendly colors like yellow/pink gradient)
- System icon "face.smiling" or similar
- Same size (26x26) and styling as other toolbar buttons
- Hover/press states matching AttachmentMenuView pattern
- Disabled state when `isLoading || isRecording`

### 2. Create EmojiService for Data and Memory

**File:** `FocusOS/Services/EmojiService.swift`

Create service class for emoji management:

- Static emoji data organized by categories:
  - Smileys & People, Animals & Nature, Food & Drink, Travel & Places, Activities, Objects, Symbols, Flags
  - Each emoji has: character, name, keywords/aliases (for fuzzy search)
- Recently used emoji storage:
  - Use `UserDefaults` or `@AppStorage` to persist recently used emojis
  - Store last 50-100 recently used emojis with timestamps
  - Method: `recordEmojiUsage(_ emoji: String)` to track usage
  - Method: `getRecentlyUsed() -> [String]` to retrieve recent emojis
- Fuzzy search functionality:
  - Method: `searchEmojis(query: String) -> [String]` 
  - Search against: emoji name, keywords, category names
  - Use fuzzy matching algorithm (Levenshtein distance or similar)
  - Return matching emojis ordered by relevance

### 3. Create EmojiDrawerView Component  

**File:** `FocusOS/Views/AIAssistant/Components/EmojiDrawerView.swift`

Create drawer view matching `MentionDrawerView.swift` style with enhanced features:

- **Header Section:**
  - Search bar at top: TextField with magnifying glass icon, placeholder "Search emojis"
  - Search filters emojis using `EmojiService.searchEmojis(query:)`
  - When search active, show filtered results only; when empty, show categories
  - "Emoji" title and icon, using `.ultraThinMaterial` background with `AuroraShimmerView`

- **Category Tabs:**
  - Horizontal scrollable tab bar below header (or search bar if search active)
  - Tabs: "Recent", "Smileys", "Animals", "Food", "Travel", "Activities", "Objects", "Symbols", "Flags"
  - Selected tab highlighted with accent color
  - Click tab to scroll to/switch to that category
  - "Recent" tab shows recently used emojis from `EmojiService.getRecentlyUsed()`

- **Content Area:**
  - ScrollView with emoji grid organized by categories (or filtered results when searching)
  - Each category as section header with icon (collapsible like MentionDrawerView)
  - Grid layout (8-10 emojis per row) using `LazyVGrid`
  - Emoji cells: 36x36pt base size
  - **Emoji Magnification (iPadOS-style):**
    - On hover/press: show enlarged preview (2-3x size, ~100-120pt)
    - Display in overlay centered above/below emoji cell
    - Smooth scale animation with spring physics
    - Show emoji name/label below magnified preview
    - Remove magnification on hover exit or after brief delay
  - Selected/hovered states with subtle background glow
  - Click/tap to select emoji and call `onSelect(emoji: String)`

- **Filtering Support:**
  - Accept `filteredKeyword: String?` parameter
  - When provided, show only matching emojis (from `:keyword` auto-detection)
  - When search query exists, prioritize search results over keyword filter

### 5. Add Emoji Keyword Detection in MentionInputField

**File:** `FocusOS/Views/Components/MentionInputField.swift`

Add emoji keyword detection (similar to slash command and hashtag detection):

- Add state variables:
  - `@State private var showEmojiAutocomplete = false`
  - `@State private var currentEmojiKeyword: String?`
  - `@State private var currentEmojiKeywordRange: NSRange?`
  - `@State private var filteredEmojis: [String] = []`
- In `handleTextChange`, check for ":" prefix after slash/hashtag detection, before mention detection:
  - When ":" is detected:
    - Extract keyword after ":" (e.g., ":smile", ":fox")
    - Filter emojis based on keyword:
      - Match against category names (e.g., "smile" → "Smileys & People", "fox" → "Animals & Nature")
      - Match against emoji keywords/descriptions (build keyword-to-emoji map)
      - If no keyword: show all emojis
    - Store keyword range for replacement when emoji selected
    - Update filtered emoji list
    - Call `onEmojiAutocompleteVisibilityChanged?(true, filteredEmojis, keyword)` to show drawer
    - Hide other autocomplete drawers (mention, hashtag, slash)
  - When space/newline after ":" detected, hide emoji drawer
- Add `onEmojiAutocompleteVisibilityChanged: ((Bool, [String], String?) -> Void)?` callback parameter
- Pass callback from `MentionNSTextView` to parent to communicate with `AuroraChatContainer`

### 6. Implement Emoji Insertion in MentionTextView

**File:** `FocusOS/Views/Components/MentionInputField.swift`

Add emoji insertion handler:

- Listen for `NSNotification.Name("EmojiSelected")` in `MentionNSTextView.Coordinator`
- Check if there's an active `currentEmojiKeywordRange`:
  - If yes: replace the ":keyword" text with the emoji character using `textView.replaceCharacters(in: currentEmojiKeywordRange, with: emoji)`
  - If no: insert emoji at current cursor position using `textView.insertText(emoji)`
- Update cursor position after insertion (move after inserted emoji)
- Trigger `textDidChange` to update styling and binding
- Clear emoji keyword state (`currentEmojiKeyword = nil`, `currentEmojiKeywordRange = nil`)
- Hide emoji drawer via callback

### 7. Update EmojiDrawerView for Filtering

**File:** `FocusOS/Views/AIAssistant/Components/EmojiDrawerView.swift`

Add filtering support:

- Add `var filteredKeyword: String?` parameter (optional)
- When `filteredKeyword` is provided:
  - Show only matching category sections
  - Filter emoji list within categories based on keyword
  - Update header to show "Emoji: [keyword]" or "Emoji (filtered)"
- When no keyword: show all categories and emojis as before

### 8. Wire Up in AuroraChatContainer

**File:** `FocusOS/Views/AIAssistant/AuroraChatContainer.swift`

- Pass `onToggleEmoji` to `AuroraChatInputBar` that toggles `showEmojiDrawer`
- Add state: `@State private var emojiFilterKeyword: String? = nil` and `@State private var filteredEmojis: [String] = []`
- Listen to emoji autocomplete visibility callback from `MentionInputField`:
  - When `onEmojiAutocompleteVisibilityChanged` is called, update `showEmojiDrawer`, `filteredEmojis`, and `emojiFilterKeyword`
- Render `EmojiDrawerView` in `conversationSection` ZStack when `showEmojiDrawer` is true
- Pass `filteredKeyword: emojiFilterKeyword` to `EmojiDrawerView`
- Handle emoji selection by posting `NSNotification.Name("EmojiSelected")` notification
- Ensure drawer closes other drawers when opened (like slash/hashtag/mention drawers)
- Hide emoji drawer when other drawers open
