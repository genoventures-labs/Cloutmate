# Slash Commands for AI Assistant

## Overview

Implement a slash command system ("/") in the AI Assistant input field that provides quick actions, context attachment, and message-specific behavior flags. Similar to how @ mentions work, but for commands and context attachment.

## Implementation Details

### 1. Slash Command Detection & Autocomplete

**File**: `Cloutmate/Views/Components/MentionInputField.swift`

- Add slash command detection similar to @ mention detection
- Track current slash command state (`currentSlashCommand`, `slashCommandRange`)
- When "/" is typed alone, show dropdown with all available commands
- As user types after "/", filter commands (e.g., "/ta" shows "tab", "task")
- Create `SlashCommandAutocompleteView` component similar to `MentionAutocompleteView`
- Commands to show:
- `/tab` - Attach tab reference
- `/think` - Enable deep thinking for this message
- `/web` - Enable web search for this message
- `/project` - Attach project reference
- `/task` - Attach task reference
- Additional commands TBD during implementation

### 2. Slash Command Handlers

**File**: `Cloutmate/Views/AIAssistant/UnifiedAIAssistantView.swift`

- Add state for message-specific flags: `@State private var messageFlags: [String: Bool] = [:]`
- Add handlers for each command:
- `handleSlashTab()` - Show tab drawer
- `handleSlashProject()` - Show project drawer
- `handleSlashTask()` - Show task drawer
- `handleSlashThink()` - Toggle think flag for current message
- `handleSlashWeb()` - Toggle web flag for current message

### 3. Tab Drawer

**File**: `Cloutmate/Views/AIAssistant/Components/TabAttachmentDrawer.swift` (new)

- Create V2 drawer using `V2DrawerScaffold`
- List all tabs (excluding AI Assistant) with icons
- On selection, attach tab reference and remove "/tab" from input
- Use same attachment system as existing tab attachment

### 4. Project Drawer

**File**: `Cloutmate/Views/AIAssistant/Components/ProjectAttachmentDrawer.swift` (new)

- Create V2 drawer using `V2DrawerScaffold`
- Query only active projects: `@Query(filter: #Predicate<Project> { $0.status == .active })`
- Display projects in list format with project name, status indicator
- On selection, attach project reference (similar to tab attachment)
- Remove "/project" from input text

### 5. Task Drawer

**File**: `Cloutmate/Views/AIAssistant/Components/TaskAttachmentDrawer.swift` (new)

- Create V2 drawer using `V2DrawerScaffold`
- Query tasks with status `.inProgress` or `.todo`
- Display tasks in list format with task name, status, due date if available
- On selection, attach task reference
- Remove "/task" from input text

### 6. Attachment System Updates

**Files**:

- `Cloutmate/Views/AIAssistant/UnifiedAIAssistantView.swift`
- `Cloutmate/Views/AIAssistant/Components/AuroraChatInputBar.swift`

- Extend attachment system to support projects and tasks (currently only tabs)
- Add `@State private var attachedProjects: [UUID] = []`
- Add `@State private var attachedTasks: [UUID] = []`
- Update `contextLabelsWithTab` to include projects and tasks
- Display attachment chips in input field (same style as tab chips)
- Each chip has "x" button to detach

### 7. Message Flags UI

**File**: `Cloutmate/Views/AIAssistant/Components/AuroraChatInputBar.swift`

- Add small visual indicators when `/think` or `/web` flags are active
- Show small badge/icon next to input field or in composer area
- Use subtle styling (small icon, low opacity)
- Clear flags when message is sent

### 8. Message Sending Integration

**File**: `Cloutmate/ViewModels/AIAssistantViewModel.swift`

- Update `sendMessage()` to accept message flags
- Pass flags to AI service: `thinkMode: messageFlags["think"] ?? false, webSearch: messageFlags["web"] ?? false`
- Include attached projects/tasks in message context
- Clear flags after sending

### 9. Slash Command Removal

**File**: `Cloutmate/Views/Components/MentionInputField.swift`

- When slash command is executed (drawer opens or flag toggled), remove the slash command text from input
- Use `currentSlashCommandRange` to replace text with empty string or selected item reference
- Handle text replacement similar to @ mention replacement

### 10. Additional Commands (Brainstorm)

Consider adding:

- `/export` - Quick export conversation
- `/summarize` - Request summary of conversation
- `/refine` - Ask Aurora to refine last response
- `/help` - Show available commands

## Data Flow

1. User types "/" → Show command dropdown
2. User types "/tab" → Show tab drawer
3. User selects tab → Attach tab, remove "/tab" from text, show chip
4. User types "/think" → Toggle think flag, show indicator, remove "/think" from text
5. User sends message → Flags and attachments included in message context

## Visual Design

- Slash command dropdown: Similar to @ mention autocomplete, but with command icons
- Attachment chips: Same style as current tab chips (capsule with gradient, "x" button)
- Flag indicators: Small icon badges (lightbulb for think, globe for web) near input field
- Drawers: V2 style using `V2DrawerScaffold`, bottom slide-up or side slide-in
