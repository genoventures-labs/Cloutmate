# Unified Notion Integration View

## Overview

Create a new full-screen view using `V2GlassContentScaffold` that consolidates all Notion integration management (except OAuth connection which stays in Settings). This replaces `NotionDatabaseSelectorView` and `NotionMappingSheet`.

## Implementation Plan

### 1. Create New Unified View File

**File:** `FocusOS/Views/Notion/UnifiedNotionIntegrationView.swift`

**Structure:**

- Uses `V2GlassContentScaffold` (full-screen, not side drawer)
- Header: "Notion Integration" with subtitle
- Main content area with sections
- Optional right sidebar for database details/configuration

**Sections:**

1. **Connected Databases List** - Shows all `NotionSyncConfig` entries

   - Database card with title, type, sync status
   - Last synced timestamp
   - Active/inactive toggle
   - Edit/Configure button
   - Remove button

2. **Add New Database** - Button/action to add database

   - Opens database selector inline or in modal
   - After selection, shows property mapping interface

3. **Database Configuration** (when editing)

   - Property mappings editor
   - Sync settings (interval, auto-sync, create/update/delete options)
   - FocusOS type selector
   - Save/Cancel actions

### 2. Database Management Components

**DatabaseCardV2** (reuse from NotionDatabaseSelectorView but enhance):

- Shows database title, FocusOS type, sync status
- Last synced time
- Active/inactive toggle
- Edit button opens configuration
- Remove button with confirmation

**PropertyMappingEditor** (extracted from NotionMappingSheet):

- List of Notion properties
- Picker for each to map to FocusOS field
- Smart matching suggestions
- Preview button

**SyncSettingsEditor**:

- Sync interval picker (hourly/daily)
- Toggles for: auto-sync, create new, update existing, delete removed
- Save button

### 3. Integration with Settings

**Update:** `FocusOS/Views/Settings/NotionIntegrationSection.swift`

- Keep only OAuth connection/disconnection
- Remove database list and management
- Add button to open `UnifiedNotionIntegrationView` when connected
- Pass `accessToken` to the unified view

### 4. Replace Existing Views

**Deprecate/Remove:**

- `NotionDatabaseSelectorView.swift` - functionality moved to unified view
- `NotionMappingSheet.swift` - functionality moved to unified view
- Update any imports/references

### 5. V2 Styling Requirements

**Use throughout:**

- `V2GlassContentScaffold` for main layout
- `V2GlassHeaderBar` for header
- `DrawerSection` for content sections
- `DashboardTile` for database cards
- `GlassButton` for actions
- `V2GlassControlStack` for settings groups
- Consistent spacing (28px horizontal, 18px vertical)
- Proper use of `glassColorSystem` for colors
- `.foregroundStyle()` instead of `.foregroundColor()`

### 6. State Management

**State variables needed:**

- `@Query` for `NotionSyncConfig` entries
- `@State` for selected database (for editing)
- `@State` for showing add database flow
- `@State` for property mappings (when editing)
- `@State` for sync settings (when editing)
- `@State` for loading/error states

### 7. Navigation Flow

1. User clicks "Manage Integration" in Settings
2. Opens `UnifiedNotionIntegrationView` as full-screen
3. Shows list of connected databases
4. User can:

   - Click "Add Database" → shows database selector → property mapping → save
   - Click "Edit" on existing → shows property mapping + sync settings → save
   - Toggle active/inactive
   - Remove database

### 8. File Structure

```
FocusOS/Views/Notion/
  ├── UnifiedNotionIntegrationView.swift (NEW - main view)
  ├── Components/
  │   ├── NotionDatabaseCard.swift (NEW - enhanced card)

  │   └── NotionSyncSettingsEditor.swift (NEW - sync config)
  └── (Keep NotionDatabaseSelectorView.swift temporarily for reference, then remove)
```

## Implementation Steps

1. Create `UnifiedNotionIntegrationView.swift` with `V2GlassContentScaffold` structure
2. Create `NotionDatabaseCard.swift` component with V2 styling
3. Create `NotionPropertyMappingEditor.swift` component (extract from NotionMappingSheet)
4. Create `NotionSyncSettingsEditor.swift` component for sync configuration
5. Implement database list section with cards
6. Implement add database flow (inline or modal)
7. Implement edit/configure flow for existing databases
8. Update `NotionIntegrationSection.swift` to open unified view
9. Test all flows (add, edit, remove, toggle active)
10. Remove deprecated `NotionDatabaseSelectorView.swift` and `NotionMappingSheet.swift`

## Key Features

- Full-screen V2 styled interface
- All database management in one place
- Inline property mapping editor
- Sync settings configuration
- Active/inactive toggles
- Remove with confirmation
- Loading and error states
- Empty state when no databases
