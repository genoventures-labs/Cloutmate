# Apple‑like Dashboard Redesign

## Goals

- Single centered hero card (Social Overview), other tiles recede.
- Four groups: Pipeline, Social, Performance, Inbox.
- Inter-like typography, tighter rhythm, higher contrast.
- Kosmic palette only (violet, cyan, gray neutrals), remove rainbow icons.
- Subtle motion on metric changes; no hard reloads.
- Friendly defaults: “Awaiting your first post.”, not placeholders.
- Keep Settings working; seed sensible defaults.

- Change: `FocusOS/Views/Dashboard/DashboardView.swift`

## Key design decisions

- Layout
- Hero: `SocialOverviewCard` centered, max width 420–520, elevated shadow, increased corner radius.
- Below hero: 2-column responsive grid of grouped panels; each group uses a subdued Glass tier.
- Limit visible starter cards to group essentials; others available via Settings.
- Typography
- Title 20–22/28 semibold; metric 28–34 bold; labels 12–13 medium, 0.5–1.0 line spacing.
- Use `.primary` with contrast adjusted via custom color tokens (gray-900 on off‑white BG).
- Palette
- Define `KosmicPalette.violet`, `.cyan`, `.neutral900`, `.neutral300`.
- Replace system icon colors with palette accents; monochrome glyphs + accent dots/badges only.
- Motion
- Wrap metric values with `.contentTransition(.numericText)` + `.animation(.easeOut(duration: 0.2), value: metric)`.
- Use `.transaction` to disable implicit layout jumps on refresh.
- Empty states
- Replace “No data” with toneful strings; e.g., Social: “Awaiting your first post.” Inbox: “All clear for now.”

## Implementation steps

1) Style system

- Create `DashboardStyle.swift` with:
- Palette enum and Color extensions
- Typography modifiers: `MetricValueStyle`, `MetricLabelStyle`, `SectionTitleStyle`
- Card chrome helpers: `heroCard()` and `supportingCard()` view modifiers

2) Group shells

- Create `DashboardGroups.swift`:
- `PipelineGroup` shows Projects Overview + Tasks Overview
- `SocialGroup` shows ContentPerformance/PlatformComparison as secondary around hero
- `PerformanceGroup` shows Completion Rate + Posting Streak
- `InboxGroup` shows InboxCount, Upcoming Deadlines
- Each group uses friendly empty states; palette accents

3) Dashboard layout

- In `DashboardView`:
- Insert hero `SocialOverviewCard` with `heroCard()` centered
- Below, render group shells in 2-column adaptive grid with `supportingCard()`
- Keep Quick Stats section removed/reduced; integrate metrics into groups
- Background remains `.background`; remove rainbow icon tints

4) Card components polish

- Update existing cards to adopt typography/palette and friendly empty states.
- Add `.contentTransition(.numericText)` and small fade for changes.

5) Settings + defaults

- Keep working Toggles; cap hero to SocialOverview (always visible, locked toggle), others configurable.
- Update default seeding to include: SocialOverview (hero), Pipeline (Projects/Tasks), Performance (Completion, Streak), Inbox (Inbox, Upcoming Deadlines).
- Maintain persistence and ordering; hero always position 0 and large.

6) Motion and refresh

- Replace hard `.id(refreshID)` reloads for metrics-only views with animated value updates where feasible; keep full refresh path for external notifications.

## Acceptance

- Hero Social Overview centered and elevated; four supporting groups below.
- Typography and colors aligned with palette; no multi‑color icons.
- Friendly default copy across empty states.
- Settings toggles work; Social Overview fixed on; defaults seeded once.
- Subtle motion on metric changes; no jarring reloads.
