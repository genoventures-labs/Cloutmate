## ✨ The Five States

| State | When It Activates | Visual Feel |

## 🚀 How to Use

### Default Behavior
ARTE activates automatically on app launch in **Auto** mode at **70% intensity**. It operates in the background, adapting the interface subtly as you work.

### Explore Settings
Navigate to **Settings → ARTE** to:
- Adjust intensity (recommended: 40-70%)
- Switch modes (Auto/Manual/Blend)
- Lock to a specific state
- View performance stats
- Reset learning data

### Monitor in Insights
Check **Insights → Overview** to see:
- Your current emotional state
- Confidence level
- Recent transitions
- Learning progress

---

## 🎓 Learning & Adaptation

ARTE learns from your behavior:
1. Tracks all state transitions
2. Records manual overrides
3. Adjusts detection thresholds (conservative 10%)
4. Improves accuracy over 1-2 weeks
5. Maintains calibration data

**Calibration improves with use.**

## 🐛 Known Limitations

**Current:**
- Simplified color manipulation (RGB-based)
- Heuristic detection (not ML-based)
- Conservative learning rate
- No cross-device sync
- No custom states

**All Non-Blocking:**
- System fully functional
- User experience unaffected
- Future enhancements possible
