## 🎨 The Five States

| Icon | State | When It Activates | Visual Feel |
|------|-------|-------------------|-------------|
| 🎯 | **Focused** | Deep work sessions, high concentration | Deep blues, cool shadows, deliberate pace |
| 🧠 | **Reflective** | Memory Graph exploration, analytical thinking | Muted purples, soft contrasts |
